# Builders

Everything visual in the place (maps, lobby, crates, UI) is generated by these modules, so a reskin is a code change rather than hours of manual edits. Rojo syncs this folder to `ServerStorage.Builders`. The builders are edit-time tools only; they don't run in a live game.

| Module | Builds |
| --- | --- |
| `Theme` | **Every color, font and the stud texture. Change this to reskin.** |
| `Environment` | Water, horizon islands, clouds, lighting. Removes the default Baseplate. |
| `MapYard` | **The launch map, "The Fireworks Yard"** (Asset Bible §4.2), into `Workspace.Maps.Yard`; also sets the Golden Fuse lighting. Park `Meadow` in `ServerStorage.Maps` first |
| `MapYardToy` | **The toy restyle of the Yard** (the owner's reference video, DECISIONS 2026-10-17). Run right after `MapYard`: recolours to the toy palette, studs, palms / voxel trees, rockets, bleachers, sunny light; restores the place offset |
| `MapYardProps` | **The Yard's modelled props.** Run after `MapYardToy`: swaps the part-built crates, hand-trucks, pallets, gas bottles and canopy floodlights for `ReplicatedStorage.FV_Art.Props.*` (import them first with `art/props/studio_import_props.luau`); a missing prop leaves the part-built one |
| `MapDepot` | **The lobby, "The Depot"** (GDD §19, Asset Bible §4.3), into `Workspace.Lobby` |
| `MapDepotToy` | **The toy restyle of the Depot.** Run right after `MapDepot`: recolours by part name (keeps every name the Depot code reads), studs, the modelled dressing crates, the crate stands and spin wheel with their prompts |
| `MapMeadow` | The temporary map (P0–P2), now parked in `ServerStorage.Maps.Meadow` |
| `MapBlossom` | Map 2, into `ServerStorage.Maps.Blossom` |
| `Lobby` | Lobby island, crates, shop, gift, wheel, event board, podium, leaderboards, plus the `LobbyFX` animation script |
| `UIHud` | `Topbar`, `HUD`, `SideRail` (+ `MenuPopup`), `Spectate`, plus the `UIAutoScale` script |
| `UIMenu` | `MainMenu` (Shop, Abilities, Items, My Knives) |
| `UIPopups` | `Crate_Solar`, `Crate_Aurora`, `MapVote` |
| `Util`, `UIKit`, `Crates` | Shared helpers |
| `Runtime/*` | Source for the scripts the builders install (`LobbyFX`, `UIAutoScale`) |

`UIHud` also installs the one-time Candy Toybox arrival screen in the persistent `UILoading` ScreenGui. Shared native button/icon geometry lives in `ReplicatedStorage.Shared.CandyUI`; ensure `src/shared` is synced before rebuilding. See `docs/UI_REDESIGN.md` for the current UI and preview instructions.

Each builder deletes what it built last time and rebuilds it, so re-running is safe. Anything you hand-place inside those generated containers is lost on rebuild; put hand-made things in their own folders.

## Rebuild

With Rojo connected, paste this into Studio's **Command Bar** (View > Command Bar). Delete the lines you don't need.

```lua
local B = game.ServerStorage.Builders
local loaded = {}
local function find(p) local i = B for s in p:gmatch("[^/]+") do i = i:WaitForChild(s, 5) end return i end
local function req(p) if not loaded[p] then loaded[p] = require(find(p):Clone()) end return loaded[p] end
local ctx = { req = req, source = function(p) return find(p).Source end }
local stored = game.ServerStorage:FindFirstChild("Maps") or Instance.new("Folder", game.ServerStorage); stored.Name = "Maps"
local maps = workspace:FindFirstChild("Maps") or Instance.new("Folder", workspace); maps.Name = "Maps"
print(req("Environment")(ctx))
print(req("MapYard")(ctx, maps))
print(req("MapYardToy")(ctx))
print(req("MapYardProps")(ctx))
print(req("MapDepot")(ctx, workspace))
print(req("MapDepotToy")(ctx))
print(req("MapMeadow")(ctx, stored))
print(req("MapBlossom")(ctx, stored))
print(req("Lobby")(ctx))
print(req("UIHud")(ctx))
print(req("UIMenu")(ctx))
print(req("UIPopups")(ctx))
```

Modules are loaded through `:Clone()` so you always get the latest synced code, not Studio's cached copy.

## Stud texture

`assets/textures/stud_tile.png` is generated by `tools/make_stud_texture.py` and uploaded as `Theme.StudTexture`. It's a transparent bevel overlay, so every part keeps its own color under it.
